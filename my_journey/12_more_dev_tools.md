# Django Development Tools

To ease development, some popular tools were added.

1. `django-debug-toolbar`
    - link: https://django-debug-toolbar.readthedocs.io/en/latest/installation.html

To inspect what is going on in the backgroudn of your django site, this tool creates a bar on your webpage which lets you track sql queries run to generate that page, track template context available to a page, and much more.

2. `django-browser-reload`
    - link: https://pypi.org/project/django-browser-reload/

This automatically reloads your web browser when files change on the server. This is useful for watching templates refresh infront of your eyes as you edit the code.
